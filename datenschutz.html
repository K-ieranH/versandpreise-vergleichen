2. Nutzung der App und Versandpreisvergleich

Für die Berechnung passender Versandangebote übermittelt die App die vom Nutzer eingegebenen Versanddaten an das Backend der Anwendung. Dazu können insbesondere Zielland, Paketmaße, Gewicht und ausgewählte Filter gehören.

Die Angaben werden zur Berechnung und Rückgabe geeigneter Versandangebote verarbeitet. Die normalen Versandpreisabfragen werden nicht dauerhaft als eigene Nutzerprofile gespeichert.

Zur technischen Absicherung und Begrenzung übermäßiger Anfragen wird die IP-Adresse vorübergehend für Rate-Limiting verarbeitet. Bei der derzeit verwendeten lokalen Rate-Limitierung erfolgt dadurch keine dauerhafte Speicherung der IP-Adresse in einer Anfragedatenbank.

3. Feedback

Über die Funktion „Fehler oder Verbesserung melden“ können Nutzer freiwillig Feedback übermitteln. Dabei werden die ausgewählte Kategorie, der Nachrichtentext und – falls angegeben – eine Quellenadresse übertragen. Zusätzlich werden App-Version und Plattform mitgesendet.

Bitte keine persönlichen oder vertraulichen Daten in das Freitextfeld eingeben. Als Bestandteil der Feedbackmeldung übermittelt die App keine Geräte-ID, Werbe-ID oder andere eindeutige Gerätekennung.

Feedbackmeldungen werden auf dem Backend zur Bearbeitung gespeichert und spätestens nach 90 Tagen automatisch gelöscht. Zusätzlich kann eine Feedbackmeldung zur Bearbeitung per E-Mail an den Verantwortlichen weitergeleitet werden. Solche E-Mails werden nur so lange aufbewahrt, wie dies für die Bearbeitung der Meldung erforderlich ist.

4. Lokal gespeicherte Einstellungen

Bestimmte vom Nutzer gewählte Einstellungen, insbesondere Standardfilter, können lokal auf dem Gerät gespeichert werden. Diese Daten dienen dazu, die gewählten Einstellungen beim nächsten Start wiederherzustellen. Sie werden hierfür nicht an das Backend übertragen.

5. Werbung mit Google AdMob

Auf unterstützten Mobilgeräten verwendet die App Google AdMob, einen Werbedienst von Google. Dabei können durch das Google Mobile Ads SDK insbesondere technische Informationen wie IP-Adresse, Geräte- oder Werbekennungen, Informationen zu Anzeigeninteraktionen sowie Diagnoseinformationen verarbeitet werden.

Soweit für den Nutzer eine Einwilligung oder Auswahl zu Werbe- und Datenschutzeinstellungen erforderlich ist, wird diese über Googles Consent-Lösung abgefragt. Werbung wird erst angefordert, wenn die hierfür erforderlichen Voraussetzungen erfüllt sind. Soweit Google erneut aufrufbare Datenschutzoptionen bereitstellt, können diese innerhalb der App geöffnet und geändert werden.

Die Verarbeitung durch Google richtet sich zusätzlich nach den Datenschutzbestimmungen und Einstellungen von Google.
